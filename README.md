Reconnaissance & Information Gathering Assessment
This repository contains a comprehensive security assessment report focusing on passive reconnaissance, active asset discovery, web traffic manipulation, and log anomaly detection. It documents a five-phase methodology used to identify infrastructure exposure, evaluate server configurations, and analyze simulated attack traffic.

Modules & Tasks
Task 1: Infrastructure & OSINT Analysis :: Netcraft

Task 2: Web Server Log Analysis :: Webalizer/AWFFull

Task 3: Asset Discovery & Risk Assessment :: Shodan

Task 4: Subdomain Enumeration & Live Host Validation

Task 5: Traffic Interception & Analysis :: Burp Suite
